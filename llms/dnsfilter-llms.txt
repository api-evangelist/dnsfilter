# DNSFilter

> DNSFilter is an AI-powered DNS security and content-filtering platform that blocks malicious domains (phishing, malware, ransomware, botnet C2) and unwanted content across 40+ categories at the DNS layer, for SMBs, enterprises, MSPs, schools, and government. Its management REST API (api.dnsfilter.com) programmatically manages organizations, networks/sites, filtering policies, block pages, API keys, and traffic/threat reporting. Authentication is an API key passed in the Authorization header.

## APIs
- [DNSFilter API](https://api.dnsfilter.com): OpenAPI 3.0, 280 operations across organizations, policies, networks, domains, block pages, applications, categories, traffic reports, and users.

## Conventions
- Auth: `Authorization: <api-key>` header (raw key, no Bearer prefix).
- Rate limiting: 429 on exceed; RateLimit, RateLimit-Policy, RateLimit-Limit, RateLimit-Remaining, RateLimit-Reset, Retry-After headers.
- Pagination: page[number] / page[size] (V1, nested object).
- Errors: V1 `{ "error": "string", "type": "..." }`; V2 `{ "error": { "message": "string", "type": "..." } }`. Not RFC 9457.
- Versioning: URI-path (/v1, /v2).
